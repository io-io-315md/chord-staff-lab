# Chord Staff Lab

コード名と大譜表を相互に変換する、ブラウザだけで動く音楽理論ツールです。

## Features

### コード → 五線譜

- ルート、コードタイプ、分数コードのベース音を選択して入力
- `Cmaj7`、`Am7`、`D7`、`F#m7b5`、`Bbmaj9`、`C/E`、`C6/9/E` などを解析
- ト音記号・ヘ音記号の大譜表に構成音を表示
- ♯ / ♭、テンション、オンコードに対応
- 構成音と度数を一覧表示

### 五線譜 → コード

- 大譜表の線・間をクリックまたはタップして音符を配置
- ♭ / ♮ / ♯ を切り替えて入力
- 最低音を使った転回形・オンコード判定
- Key center（Major / Minor）を加味した候補ランキング
- 完全一致と近似一致を最大8件表示

## Run locally

依存パッケージはありません。ローカルサーバーで `index.html` を配信してください。

```sh
python -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

## Test

Node.js 18以上で実行できます。

```sh
npm test
```

## Deploy

すべて相対パスの静的ファイルなので、GitHub Pages の **Deploy from a branch** でそのまま公開できます。
